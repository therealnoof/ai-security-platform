## Top Stories

### NEAR AI Suffers Production Breach via SGLang Remote Code Execution

On November 9, 2026 NEAR AI reported that an attacker used a remote code execution flaw in SGLang, the open-source inference engine, to run code on one of its inference servers. That server processes confidential-mode requests inside a trusted execution environment, and NEAR AI says the attacker could have seen requests on it on November 8, including confidential ones.

The incident is significant for three reasons. First, it demonstrates that inference servers—not just model endpoints—are being actively targeted and successfully compromised. SGLang is widely deployed for high-throughput LLM serving, and the RCE flaw allowed the attacker to bypass application-layer controls and reach the operating system.

Second, the breach affected confidential compute. NEAR AI's use of a trusted execution environment (TEE) was intended to protect sensitive inference requests from both the cloud provider and NEAR AI's own operations team. The fact that an application-layer RCE allowed the attacker to see requests processed inside the TEE underscores a gap: TEEs protect against infrastructure-level threats, but they do not isolate workloads from vulnerabilities in the serving software running *inside* the enclave.

Third, the timeline is compressed. The attack occurred on November 8, and NEAR AI disclosed it on November 9—a 24-hour window from compromise to public notification. Organizations should audit their inference infrastructure for SGLang deployments, review access logs for the November 7-9 window, and confirm that inference servers are not exposed to untrusted networks without additional hardening.

### CrowdStrike Acquires $495M in Agent Security; Market Consolidates

CrowdStrike has reportedly acquired two AI agent security startups for $495 million, according to multiple reports published November 14-15. The acquisitions follow last week's announcement that Palo Alto Networks is in advanced talks to acquire Clutch Security for $500M, signaling that AI agent security has transitioned from point-solution startups to strategic acquisitions by major security vendors.

The timing matters. Last week, CrowdStrike introduced an AI Kill Switch in Falcon Guardian, allowing administrators to terminate misbehaving agents, block relaunches, and cut network access. This week's acquisitions suggest CrowdStrike is now integrating runtime observability, policy enforcement, and agent-specific threat detection into its core platform—capabilities that complement the kill switch but require deep instrumentation of agentic workflows.

For security teams, this consolidation accelerates product maturity. Within the next 12-18 months, organizations should expect agent security features to migrate from standalone vendors into existing EDR, SIEM, and CNAPP platforms. Teams evaluating standalone agent security tools should ask vendors about acquisition risk and integration roadmaps, while those with existing CrowdStrike, Palo Alto, or Microsoft deployments should monitor product updates for new agent-specific capabilities.

The $495M price tag also sets a valuation floor. Agent security is no longer a "wait and see" category—it is a billion-dollar market that established vendors are willing to pay premium multiples to enter.

### Google DeepMind Formally Verifies Signal's libsignal with AlphaProof Code

Google DeepMind published a research blog introducing AlphaProof Code, a multi-LLM, agentic framework that generated over six million lines of machine-checked Lean proofs and formally verified key security properties of Signal's libsignal implementation in about four weeks.

The achievement is notable because libsignal is production cryptographic software used by hundreds of millions of Signal users. Formal verification—proving mathematically that code implements a specification without bugs—has historically been limited to small, safety-critical components due to the manual effort required. AlphaProof Code automates most of that effort, with humans reviewing one percent of the results.

For security practitioners, this represents a shift in what is practical. Formal verification is no longer reserved for aerospace, medical devices, or cryptographic primitives—it is now feasible for libraries, protocols, and even security-critical application logic. Organizations building or deploying AI agents in regulated environments (healthcare, finance, critical infrastructure) should consider agentic formal verification as a viable assurance option, particularly for components where traditional testing and code review leave residual risk.

The research also highlights a broader trend: AI is now being used to secure AI. Last week's GPT-6 Cyber discovers vulnerabilities at machine speed; this week's AlphaProof Code verifies fixes at comparable scale. The gap between offense and defense is narrowing, but only for organizations that invest in tooling and workflows to operationalize these capabilities.

## Vulnerability Watch

### Inference Server and ML Framework CVEs

**CVE-2026-24747: PyTorch weights_only Remote Code Execution (CVSS 8.8)**

CVE-2026-24747 is a remote code execution vulnerability in PyTorch's weights_only unpickler that allows attackers to execute arbitrary code via malicious checkpoint files. Prior to version 2.10.0, a vulnerability in PyTorch's weights_only unpickler allows an attacker to craft a malicious checkpoint file (.pth) that, when loaded with torch.load(..., weights_only=True), can corrupt memory and potentially lead to arbitrary code execution. Version 2.10.0 fixes the issue. Published January 27, 2026.

**CVE-2026-34070: LangChain Path Traversal in Prompt Loading (CVSS 7.5)**

CVE-2026-34070 (CVSS 7.5) introduces a path traversal flaw in LangChain's prompt-loading subsystem, allowing an attacker to read arbitrary files from the host filesystem. Patches addressing CVE-2026-34070 are included in langchain-core version 1.2.22 and later. Disclosed March 27, 2026 by Vladimir Tokarev of Cyera.

**CVE-2026-7482: Ollama "Bleeding Llama" Heap Memory Leak (CVSS 9.1 / 8.8)**

Approximately 175,000 Ollama instances are publicly accessible on the internet with no authentication by default, and CVE-2026-7482 ("Bleeding Llama") allows unauthenticated attackers to extract API keys, environment variables, and conversation data from any unpatched server using three API calls. Ollama CVE-2026-7482 is a heap out-of-bounds read whose leaked memory may include environment variables, API keys, system prompts and concurrent users' conversation data. Fixed in Ollama 0.17.1; disclosed May 2026.

**CVE-2026-103663: Ollama Path Traversal via /api/pull**

Anything from 0.34.2 up to 0.35.0 is affected. Versions 0.34.2 up to 0.35.0. The fix is in 0.35.0. The layer digest isn't validated properly, so an unauthenticated request can make Ollama write a file outside its model store. Disclosed October 8, 2026 by CERT Polska.

**CVE-2026-5757: Ollama Information Disclosure (Unpatched Zero-Day)**

CVE-2026-5757 is a critical zero-day Information Disclosure, Out-of-Bounds Read, and Memory Corruption vulnerability affecting Ollama, the widely deployed open-source platform for running large language models locally. Because no official patch exists for CVE-2026-5757, vendors must implement network-level mitigations immediately. Status: Unpatched.

## Research Spotlight

**[Scaling Adaptive Prompt Injection Attacks with Agent Swarms](https://arxiv.org/abs/2611.11861)** (arXiv:2611.11861, November 9, 2026)

Prompt injections have emerged as one of the top security risks faced by AI agents today. Early work in prompt injection attacks looked at simple tool-call agents and static attack payloads, and were saturated since mid-2025. As of Fall 2026, human red-teaming may be nearing saturation, especially on the Gemini family of models. In this work, we argue that despite this apparent plateau, prompt injection attacks are still possible and continued effort into prompt injection defense is needed. Lead author: Alexey Kurakin (Google).

**[Adversarial Déjà Vu: Jailbreak Dictionary Learning for Stronger Generalization to Unseen Attacks](https://proceedings.iclr.cc/paper_files/paper/2026/file/ab41709d06e9303c25ad6742ae661198-Paper-Conference.pdf)** (ICLR 2026)

This paper proposes a new paradigm for improving robustness against unseen jailbreaks, centered on the Adversarial Déjà Vu hypothesis: novel jailbreaks are not fundamentally new, but largely recombinations of adversarial skills from previous attacks. The research introduces dictionary learning to identify transferable adversarial skill primitives across jailbreak families.

## What This Means For You

**Audit your inference infrastructure this week.** The NEAR AI breach demonstrates that inference servers are active targets. If you are running SGLang, Ollama, vLLM, or other open-source serving frameworks, treat them as internet-facing attack surface. Implement network segmentation, disable unnecessary endpoints, enforce authentication, and audit access logs for the November 7-15 window. If you are using confidential compute (TEEs), understand that application-layer vulnerabilities can compromise workloads *inside* the enclave—isolation protects against infrastructure threats, not software bugs.

**Prepare for agent security consolidation.** CrowdStrike's $495M acquisition and Palo Alto's $500M Clutch deal signal that agent security is consolidating into established platforms. If you are evaluating standalone agent security vendors, ask about acquisition plans and integration roadmaps. If you already deploy CrowdStrike, Palo Alto, or Microsoft security tools, monitor product updates for new agent-specific features—runtime observability, policy enforcement, and kill switches are likely to appear in the next 12-18 months as acquired capabilities integrate.

**Upgrade LangChain immediately.** CVE-2026-34070 (CVSS 7.5) allows path traversal in prompt loading, enabling arbitrary file reads. Upgrade to langchain-core 1.2.22 or later. Review your agent workflows for any use of the prompt-loading API, and audit file-system access patterns. If upgrading is blocked by dependency conflicts, isolate LangChain-based agents in sandboxes with restricted file-system access.
